# Phoenix valuation and PR contribution

## Scope

This is an indicative software/IP sale estimate, not a formal company valuation.
The ranges are buyer-value ranges in USD and are not additive. A buyer will
price the integrated, working asset rather than pay separately for every PR.

## Current estimate

| Scenario | Indicative value | Why |
|---|---:|---|
| Code/IP asset sale today | $25k-$100k | Working research system, substantial code and tests, but no verified production evidence, revenue, or independent sign-off |
| Strategic buyer with technical diligence | $75k-$250k | Higher if the buyer values the payoff engine, AI committee, provenance, and memory controls |
| After real OOS/evidence + pilot customer | $250k-$750k | Requires verified data, independent review, authenticated deployment, and a documented pilot |
| Replacement-cost reference | $150k-$400k | Approximate engineering replacement cost; not the same as sale price |

Current best honest headline: **about $50k-$150k as an integrated
research/IP asset**, with upside only after evidence, customer traction, and
independent review are real.

## Biggest price blockers

1. No verified chronological fixed-24m OOS evidence at 6/12/18/24.
2. No independent baseline comparison using real settled outcomes.
3. Incomplete field-level provenance and quote-fit for real dealer data.
4. No independent model-risk/compliance/suitability sign-off.
5. Streamlit is research/demo hosting, not a complete client production control plane.
6. No live rollback drill and approved key-custody process.

## Highest-value next work

The highest return is not another UI PR. It is a structured evidence packet from
the requester’s quotes, followed by leakage-safe OOS/baseline computation,
independent review, a staging rollback drill, and a customer pilot.
