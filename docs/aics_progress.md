## Проверяемые этапы

1. Реестр первичных источников.
2. Архив кандидатов данных (не означает независимый PIT).
3. Независимо проверенная историческая доступность (PIT).
4. Аудированная методология 0–100 для узла.
5. Независимый 24-месячный OOS.
6. Независимая сертификация узла.

Исходный архив: [GitHub Actions](https://github.com/nikitamalinovskiybcs-beep/Fly/actions/runs/44313687138).
ALFRED поддерживает три кандидатных узла. Верифицированные по SHA-256 IR-архивы добавляют Insurers, Neoclouds, SPV, Hyperscalers, Semiconductors Supply, AI Demand и Power/Data Centers лишь на этапе архива (2/6).
Отдельно: 7 JSON Nasdaq, 441 исходная запись — AI Equities только 2/6, не PIT.
IR-архивы GitHub Actions хранятся 30 дней, не являются доказательством исторического PIT, структуры SPV или сертифицированных стресс-скоров.
