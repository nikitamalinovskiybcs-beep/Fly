### Запись исследовательского решения

Предложение `AICS-20261119-source-review` принято для исследовательских расчётов. Проверки OpenAI Codex по договорам, источникам эмитентов и частным вложениям проводились в рамках одного поставщика. Название конкретной версии развёрнутой модели не установлено. Внешние поставщики оценок и независимые аудиторы в этом решении не участвовали. Замечания о дате фактической публикации, отраслевом охвате и различии между лимитом и полученной суммой отражены в таблице. Базовая отметка и результат после проверки источников составляют 22/66. Проверяемый результат этой работы — воспроизводимые факты и поимённые ссылки. Независимая PIT-аттестация остаётся следующим этапом.

### Воспроизведение

Восемь полных пакетов EDGAR хранят исходное содержимое форм и приложений, метаданные подачи и принадлежность эмитенту. Для ФРС используется текстовая версия датированного выпуска. Каждая загрузка проходит проверку SHA-256. Для SEC дополнительно проверяются accession, CIK, форма, дата подачи, имя и тип вложенного документа, а также контрольная сумма его раздела TEXT. Скрипт извлекает сопоставимые единицы, периоды и значения из этих оригиналов. [Реестр оригиналов](../aics_data/source_registry/observed_review_2026-11-19.json) · [Результаты расчёта](../aics_data/research/observed_source_review_2026-11-19.json)

```bash
python -m scripts.aics_observed_source_review --fetch --originals /tmp/aics-review-originals --out /tmp/aics-source-review.json
cmp /tmp/aics-source-review.json aics_data/research/observed_source_review_2026-11-19.json
python -m unittest discover -s tests -p 'test_aics*.py'
```

Повторная загрузка всех девяти исходников прошла в GitHub Actions. Полученный JSON совпал байт в байт с версией в репозитории. Из GitHub повторно скачан ZIP 14501014762. Локально проверены его девять исходных файлов и JSON расчёта. Контрольная сумма ZIP `29e9dbb517804e4ec4cf3b2c7585a3343a06cc7a9779791b741eab0c3b84c4bc`. Срок хранения в Actions — до 19 декабря 2026 года. [Запуск с оригиналами](https://github.com/nikitamalinovskiybcs-beep/Fly/actions/runs/44465369244)

Проверку частных вложений можно повторить в каталоге, где доступны переданные пользователем PDF и ZIP. Команда сверяет названия по текстовому слою PDF и данные JPEG с двумя описями. Для чтения PDF требуется `pdftotext`.

```bash
python -m scripts.aics_audit_company_attachments --pdf AICS_OMI_Brace_for_Impact_original_2026.pdf --telegram-zip AICS_telegram_11_screens_source_2026-11-18.zip --out /tmp/aics-attachment-review.json
cmp /tmp/aics-attachment-review.json aics_data/research/company_attachment_review_2026-11-19.json
```
