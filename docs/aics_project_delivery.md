# AICS — готовность проекта к выпуску

20 ноября 2026 года · **46/66 (69,7%)**. Каждый из 11 узлов приносит по одному баллу за каждый из шести результатов. Процент равен числу принятых результатов, делённому на 66. Веса финансового индекса считаются отдельно.

1. Определены первичные источники узла.
2. Сохранён архив исходных данных.
3. Из источника извлечён датированный показатель узла с единицей измерения. Для AI Equities выбран показатель корзины.
4. По исходным величинам получен проверяемый расчёт с понятным экономическим смыслом.
5. Реализован и воспроизводится расчёт оценки узла от 0 до 100 по зафиксированной формуле с контролем доступности входов на дату.
6. Завершена независимая проверка источников, формулы и результата на нетронутой 24-месячной выборке, узел сертифицирован.

Для следующего балла по AI Equities нужен датированный показатель корзины с подтверждённым составом и обработкой корпоративных действий. Четыре исследовательские формулы рассчитаны на срез 18 ноября. Для UST 30Y оценка 78,26 — процентиль октябрьской волатильности среди 23 предыдущих месяцев. У Neoclouds (75,78) и Hyperscalers (13,09) оценка равна доле квартальных капитальных покупок, не покрытой совокупным операционным потоком выбранных эмитентов, с ограничением диапазона 0–100. Для SPV (33,95) использовано отношение суммы долга к сумме лимитов двух линий CoreWeave. Эти исследовательские определения выбраны ретроспективно; независимая проверка и секторная репрезентативность открыты. [Воспроизвести срез](../scripts/aics_four_node_snapshot.py). Отдельная шкала аудита сохраняет прежние критерии и историю.
