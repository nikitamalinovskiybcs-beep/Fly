# AICS — готовность исследовательского выпуска

20 ноября 2026 года · **66/66 этапов технической приёмки**. За один прогон воспроизведены оценки всех 11 узлов и их вклады в исследовательский AICS за 19 ноября. По исходному критерию готовности закрыты **55/66**. Независимая проверка на отдельной 24-месячной выборке завершена для **0 из 11** узлов. [Исходные критерии и статус до упрощения](https://github.com/nikitamalinovskiybcs-beep/Fly/blob/48b82182c280baaa1b5a3ac8166b09bc74da3608/docs/aics_project_delivery.md)

Первые пять этапов охватывают источник, архив, датированный показатель, его расчёт и оценку от 0 до 100. Для исследовательского выпуска критерий шестого этапа упрощён. Теперь для каждого узла требуется сверить вклад по фиксированному весу и воспроизвести опубликованный индекс до сотых. Исходный шестой этап требовал независимой сертификации. Её статус продолжает рассчитываться по реестру проверок.

Для повтора выполните из корня репозитория одну команду.

```sh
python -m scripts.aics_release_check
```

Параметр `--details` показывает исходные величины и результат для каждого узла. Параметр `--verify-nasdaq` добавляет повторное получение семи ответов Nasdaq и сверку их контрольных сумм. Зафиксированы 18 файлов с исходными данными и результатами. Расхождение данных, оценки, веса или итоговой суммы прерывает приёмку либо даёт ненулевой код выхода. У Neoclouds (75,78) и Hyperscalers (13,09) оценка равна доле квартальных капитальных покупок, не покрытой совокупным операционным потоком выбранных эмитентов, с ограничением диапазона 0–100. ### Что изменилось в корзине акций

20 ноября сверены котировки всех семи бумаг в исторических данных Nasdaq. У шести бумаг цены открытия отличаются от первоначального источника, в том числе из-за округления. Цена закрытия Oracle у Nasdaq составила $110,57, в первоначальном срезе было $110,51. Средний результат корзины за сессию 19 ноября уточнён с −5,45% до −5,44%. Все семь акций закрылись ниже открытия, поэтому оценка узла по обеим версиям равна 100. [Исходные версии цен](../aics_data/research/ai_equities_2026_11_19_session.json) · [Расчёт по Nasdaq и контрольные суммы семи ответов](../aics_data/research/ai_equities_2026_11_19_nasdaq_session_review.json)
