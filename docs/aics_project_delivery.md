# AICS — готовность проекта к выпуску

20 ноября 2026 года · **55/66 (83,3%)**. Каждый из 11 узлов приносит по одному баллу за каждый из шести результатов. Процент равен числу принятых результатов, делённому на 66. Веса финансового индекса считаются отдельно.

1. Определены первичные источники узла.
2. Сохранён архив исходных данных.
3. Из источника извлечён датированный показатель узла с единицей измерения. Для AI Equities выбран показатель корзины.
4. По исходным величинам получен проверяемый расчёт с понятным экономическим смыслом.
5. Реализован и воспроизводится расчёт оценки узла от 0 до 100 по зафиксированной формуле с контролем доступности входов на дату.
6. Завершена независимая проверка источников, формулы и результата на нетронутой 24-месячной выборке, узел сертифицирован.
