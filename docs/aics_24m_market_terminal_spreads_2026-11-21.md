# AICS · месячный рынок и спреды · терминальный вид

**Период:** 24 завершённых месяца, ноябрь 2024 — октябрь 2026. **Модель:** без множителя, общая сумма весов 1050. **Статус:** исследовательский, ретроспективно собранные открытые данные. Это самостоятельный терминальный дизайн, **не Bloomberg, не Bloomberg API и не лицензированные котировки Bloomberg**.

Важно: два разных спреда имеют разные значения и единицы. Рыночный *NDX−SPX* измеряется в процентных пунктах относительной доходности индексов; **SOFR−IORB** — в базисных пунктах ставок. Не складывать их между собой.

Рыночная статистика основана на [S&P 500 по месяцам, StatMuse](https://www.statmuse.com/money/ask/s-and-p-500-monthly-closing-price-from-november-2024-to-october-2026), [Nasdaq-100 по месяцам, Digrin](https://www.digrin.com/stocks/detail/%5ENDX/price), [UST30 ALFRED из проекта](../aics_data/research/ust30_yield_change_volatility_2024_2026.json), [NY Fed Repo из проекта](../aics_data/research/repo_24_month_observed_research_2026-11-18.json). Для исторического market-PIT исходные котировки поступили ретроспективно; отдельного независимого аудита «всё было опубликовано именно тогда» нет.

### Честный статус AICS

Полный месячный **AICS без множителя** за данный период остаётся **N/A (0/24)**: нет 11 датированных сопоставимых узлов на каждый месяц. Исторический **AICS−S&P 500** спред также **N/A (0/24)**. Арифметическая частичная сумма 413,27 пункта на октябрь — только 8 узлов из 11; это **не показатель AICS**. Не ставить нули вместо трёх отсутствующих узлов и не нормировать частичную сумму к S&P 500.

**20 ноября 2026:** отдельный IR shadow AICS без множителя = **528,74** по предварительным финансовым отчётам, не относящийся к серии ноябрь 2024 — октябрь 2026. Он не позволяет получить историческую доходность или вычислить 24 спреда.
