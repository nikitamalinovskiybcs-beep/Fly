Источник: [`scripts/aics_v56_prospective_feedback_learner.py`](../scripts/aics_v56_prospective_feedback_learner.py); реальные прогнозы и источники поступают только через [изначально пустой журнал](../aics_data/research/aics_v56_prospective_forecast_outcome_ledger.json), а не через исторический backfill.
3. **Правило обучения заранее зарегистрировано:**
   - Ровно пять ранее зафиксированных моделей; начальные веса **0.20** каждой. Нельзя заменять победителей молча.
   - Целевой secondary research-label обучения — **падение закрытия S&P 500 не менее чем на 5% от конца текущего месяца до закрытия следующего**. Метка появляется только после реального опубликованного закрытия следующего месяца, а не в момент исходного прогноза.
   - **Не менее 12 созревших новых месячных меток**, не менее **2 положительных месяцев**, не менее **2 отрицательных месяцев** и **2 разных эпизодов** падения. До выполнения всех условий **никакого самообновления весов**.
   - Если выполнены: `loss_j = sum_t((risk_j_t/100 - observed_binary_5pct_t)^2)`; `softmax_j = exp(-0.5*loss_j)/sum_k exp(-0.5*loss_k)`; `weight_j = 0.75/5 + 0.25*softmax_j`. Это **порядковый исследовательский surrogate-loss**, а **не калиброванная вероятность кризиса** или статистически доказанная Brier-accuracy. Ограничения каждого веса **0.15–0.40**; сумма 1.
   - Время обучения воспроизводится для **каждого исторического прогноза отдельно**: в прогнозе месяца `t` используются только исходы с фактическим `retrieved_at` раньше его времени `forecast_created_at`. Никаких исправлений прежних решений результатами будущих месяцев.
   - **10%-кризисная цель сохраняется независимой** и не используется для обновления весов; после наблюдений к ней потребуются отдельные проспективные тесты.
4. **Еженедельная автономная переоценка:** [workflow `aics-v56-feedback-learner.yml`](../.github/workflows/aics-v56-feedback-learner.yml), планировщик GitHub Actions **каждый понедельник в 09:15 UTC**, а также запуск при добавлении новых source records и вручную. Каждая успешная проверка сохраняет JSON с текущими весами и получает независимый артефакт конкретного Actions-run.

## Почему пока нельзя говорить «модель сама учится на новых реальных данных»

- Джоб GitHub по расписанию **только перерасчитывает** уже внесённые фактические source receipts. Он **не скачивает автоматически все 11 признаков**, не создаёт будущие значения индекса и не берёт права на лицензированные рыночные цены. Для завершённого data→forecast→label цикла нужно подключить провайдерские **первые захваты** новых месячных данных, а не придумывать цену S&P 500 и даты публикации.
- Исходные score/100 **не являются подтверждённой вероятностью** падения. Поэтому V56 — честный исследовательский **online ranking/feedback challenger**, а не автономный калиброванный торговый алгоритм.
- На GitHub пока **нет независимого аудита неизменности старых записей и первичной публикации**. Входящий HTTPS URL и строка SHA256 необходимы для трассировки, но **не доказывают** первоисточник без фактической сверки байтов и подтверждения `first_seen`.
- Сам GPT в результате не переобучается. Не запускаются 100 отдельных самоуправляемых агентов: 100 V53-стратегий остаются детерминированными моделями; V56 автоматизирует только адаптивные веса **пяти** из них.
- Адаптация **не изменяет** фиксированные 11 весов/пороги AICS, статус 22/66, (H>60) множитель, официальный индекс `null` и отсутствие сделок.

## Следующий узкий реальный шаг

Только после официального месячного закрытия ноября 2026:

1. Сохранить настоящий рыночный close с URI, хешем первичного ответа и `retrieved_at_utc`.
2. Получить все **11 фактических признаков V55 shadow-моделей** (`B,S,BM2,SM3,BM3,SM2,loss3,loss1,vol,accelB,accelS`) из **существующих** источников, каждое значение со своим timestamp и SHA.
3. Разово записать источник нового прогноза **до** наблюдения исхода следующего месяца; хешировать и независимо проверить source first publication.
4. Когда через месяцы появятся реальные будущие закрытия и накопится минимальная обучающая выборка, V56 **без нашего повторного выбора алгоритмов** пересчитает веса. Новые веса — только для следующих исследовательских оценок.

Главный прогресс V56: **разработана и проверена механика причинно-корректного самообучения на будущих метках с автообновлением исследовательских весов**. До поступления реально наблюдаемых событий обещать рост точности или «самообучение уже идёт» нельзя.
