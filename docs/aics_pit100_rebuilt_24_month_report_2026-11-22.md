# AICS PIT100 — полный пересчёт 24 месяцев с датой официальной публикации SEC

**Дата:** 2026-11-22. **GitHub Actions:** [проверка и пересборка](https://github.com/nikitamalinovskiybcs-beep/Fly/actions/runs/45007794686). Результат полного job нужно проверять по текущему статусу Actions; успешное прохождение отдельных тестов не является подтверждением успешного полного CI.

## Что действительно пересобрано в коде

1. Сохранены и сверены **100 выполненных PIT-аудитов** по **100 уникальным историческим датам**, из них **30 прежних исследовательских ролей** и **70 дополнительных специализированных ролей**. Это детерминированные исследовательские задачи, а не 100 обученных нейросетей.
2. Для **24 рыночных** и **24 календарных** месячных срезов написан **полный перерасчёт из исходного журнала событий**, а не копирование прежних месячных оценок. В результате есть **48 отдельных помесячных строк** с полями исходного события, даты, отсутствующих узлов и сравнения со старой версией.
3. Дата допуска SEC в новом *исследовательском* режиме — **дата официальной подачи/публикации** (без +14 дней). Для торгового закрытия без точного и независимо подтверждённого времени публикации применяется более строгая проверка: данные этого же дня нельзя автоматически использовать до закрытия. Для календарного конца дня дата SEC допускается только как **date-only research proxy**, не доказательство доставки исторического архива.
4. Семь квартальных BDC/Private Credit событий включаются в единый event ledger только при доступности исходного набора из трёх компаний. Применяется прежний **90-дневный максимум переноса** для квартального исследовательского наблюдения, без заполнения отсутствующих значений нулём.
5. В каждом месяце сохраняются фактический список присутствующих узлов, отсутствующих узлов, сумма их фиксированных весов, **частичный исследовательский weighted score** и исходный event id. Полный AICS остаётся `null`, если нет доказательств всех 11 PIT-сертифицированных узлов. Весовая сумма неизменна: **1050**.
6. Два отчёта изменений содержат по 24 строки: **newly_present_nodes**, **no_longer_present_nodes**, **changed_research_score_nodes**, сравнение known weights и частичных баллов. Разница между новыми и прежними исследованиями — **не** доказательство инвестиционного опережения.
7. Данные с исторически пересмотренными FRED/ALFRED винтажами, составы корзины AI Equities и независимые first provider delivery receipts **не** объявляются сертифицированными задним числом.

## Качество модели — статус после пересборки

| Контроль | Статус |
|---|---|
| Исследовательские PIT-аудиты | 100 уникальных исторических дат |
| Рыночные месячные срезы | 24 пересчитываются из первичных событий |
| Календарные месячные срезы | 24 пересчитываются из первичных событий |
| Искусственное ожидание SEC +14 | **Отменено в новом PIT100 режиме** |
| Подтверждение исторической поставки оригинальных байтов | Не выполнено |
| Независимая PIT-сертификация 11 узлов | **0/11** |
| Полный production AICS | **null** |
| Независимый 24-месячный OOS | Нет |
| Доказанная прогнозная точность 2000/2008 | Нет |
| Торговые сигналы и исполненные сделки | **0** |
| Подтверждённые проектные этапы | **22/66**, не 100% |

**Принцип:** увеличение числа агентов и тестов не должно повышать оценку точности модели без независимых исторических доказательств и walk-forward проверки. Дата SEC подачи сама по себе не доказывает, что исходные данные можно было прочитать и использовать до закрытия конкретной торговой сессии.

## Следующие реальные пробелы

Для финальной таблицы AICS против S&P500 нужны: (a) оригинальные SEC acceptance timestamps / first publisher delivery, (b) датированные первичные винтажи макроданных, (c) исторически зафиксированный состав AI Equities и corporate actions, (d) заранее фиксированная функция оценки каждого из 11 узлов, (e) независимый 24-месячный walk-forward OOS. Пока этого нет, нельзя утверждать, что модель предсказала падения 2000/2008 или что торговый порог 450/500 был проверен на независимых данных.
